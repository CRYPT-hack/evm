⚡ Election Simulation

Generates a random election, sends data to the C++ verifier via Python subprocess, and displays results with verification status — all in one click.

How Simulation Works Clicking the button below triggers a POST to /run_simulation in Flask. Python resets current votes, randomly assigns votes for a random subset of voters, writes election_data.txt, and calls the compiled C++ verifier. Results are returned as JSON and rendered below without reloading the page.

⚠ This resets all current votes. Existing data will be replaced by simulated data.

What C++ Checks During Simulation
1. Set Theory

Verifies voter ID set has no duplicates using std::set.

2. Functions

Checks every vote maps to a valid candidate in the codomain.

3. Counting Principle

Σ votes(cᵢ) must equal total valid votes cast.

4. Logic Constraint

All vote counts must satisfy votes(c) ≥ 0.

5. Unique TXNs

Transaction ID set must equal the number of vote records.

6. Pigeonhole

votes.size() ≤ registered_voters; otherwise contradiction.
