How it Works
1️⃣

Voter Logs In

Voter enters ID, name, and PIN. Python Flask validates credentials against voters.json.

2️⃣

Vote is Cast

Voter selects a candidate. Flask records voter ID, candidate, timestamp, and a unique transaction ID in votes.json.

3️⃣

C++ Verifies

Python calls the compiled C++ verifier via subprocess. C++ applies 6 discrete math checks and returns results.

4️⃣

Results Displayed

Flask reads C++ output, calculates winner using counting principle, and renders the results page.
